# One-Line Office Joke: 24-Hour Sprint

```
I put "quick sync" in the invite because "forty-five minutes of emotional hostage-taking" was too long.
```

A sharp one-liner satirizing corporate calendar culture and the euphemism of "quick sync" meetings that spiral out of control.
